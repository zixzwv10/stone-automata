What is this?

A grid where each cell holds stones. Every cell has a rule that moves its stones. Rules run at the same time.

How to play

Select cells. Set stones with number keys or arrows. Write rules in the editor. Press . to apply. Press Play.

Rules

send 1 right or wait. Use if/elif/else with and, or, not.

if stones == 1: send 1 up

if 2 < stones < 5: send stones down

Import / Export

Export copies board as text. Import reads text and restores board.
